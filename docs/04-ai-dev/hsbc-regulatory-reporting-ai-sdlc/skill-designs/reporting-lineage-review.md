# Skill Design: reporting-lineage-review

## Purpose

检查报送字段从源数据、转换规则到监管报表字段和提交证据的完整血缘。

## Trigger

新增或修改报表字段、计算规则、映射、数据源、报送版本或回补流程时触发。

## Checks

- 每个报表字段都有源字段或明确的人工来源。
- 每个转换步骤有规则版本、责任人和测试。
- 聚合、过滤、舍入、币种转换和时间窗口有定义。
- 规则适用市场、报表版本和频率明确。
- 异常、缺失、重复和迟到数据有处理路径。
- 报送批次、回执和重算结果可以通过证据 ID 定位。
- 追溯矩阵不包含敏感值，只包含元数据和哈希。

## Outputs

- 更新后的 `traceability-matrix.md`
- 缺口列表
- 规则和测试映射
- 报送证据要求

## Human gate

业务数据负责人确认字段含义，合规负责人确认监管解释，QA 确认测试覆盖。任何未解释缺口阻止发布。

## Deterministic controls

CI 检查矩阵空值、重复 Key、孤立字段和没有测试证据的规则。
