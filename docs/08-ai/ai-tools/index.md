# AI 工具

AI 开发工具介绍与使用。

- [Microsoft Skill Recorder](skill-recorder.md)：将一次真实操作转换为可复用的 AI Skill 或 Automation。
- [DeepSeek Harness](deepseek-harness.md)：面向 Agent 的运行时、工具编排和 Skill 扩展框架。
- [CodeGraph](codegraph.md)：通过 MCP 将代码结构、符号和依赖关系提供给 AI Agent。
- [html-ppt](html-ppt.md)：将 HTML 内容和布局转换为 PowerPoint 演示文稿。
- [Superpowers：从工程工作流到 Skill 源码](superpowers.md)：合并介绍 Superpowers 的工程流程、Skill 机制与源码分析。
- [Playwright](playwright.md)：用于浏览器自动化、端到端测试和 Trace 回放。
- [动态代码分析工具](dynamic-code-analysis.md)：在运行时观察调用、性能、覆盖率和数据流。
- [Code Tracker](code-tracker.md)：追踪代码变化、符号关系、调用链和影响范围。
- [Workflow Snapshot & Replay](workflow-snapshot-replay.md)：保存和回放 Agent 或自动化工作流的中间状态。
