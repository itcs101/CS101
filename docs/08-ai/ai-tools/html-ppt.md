# html-ppt

[html-ppt](https://github.com/shxlsp/ppt) 是一个将 HTML 内容转换为 PowerPoint 演示文稿的工具。它适合把网页式排版、数据看板或 AI 生成的 HTML 页面进一步整理成可分享、可编辑的 PPT 文件。

## 核心思路

html-ppt 以 HTML 作为内容和布局的表达方式，再将页面结构映射为 PowerPoint 幻灯片。相比直接从零编写 PPT XML，HTML 更适合快速组织标题、段落、表格、图片和卡片式布局，也便于与前端模板和 AI 生成流程结合。

典型流程是：

1. 准备包含内容和样式的 HTML。
2. 按幻灯片边界组织页面或幻灯片容器。
3. 调用 html-ppt 进行渲染或导出。
4. 在 PowerPoint 中检查字体、图片、表格和分页效果。
5. 对导出文件进行人工调整后再发布。

## 适合的场景

- 将 Markdown、报告或网页内容生成演示文稿
- 把数据看板或运营页面转换成汇报材料
- 使用 HTML/CSS 快速制作有固定视觉模板的幻灯片
- 将 AI 生成的页面内容导出为 PPTX
- 批量生成结构相似的周报、项目汇报和产品介绍

## HTML 与 PPT 的差异

HTML 是流式布局，页面会根据容器和字体自动排列；PowerPoint 更接近固定画布，每个元素都有明确位置。因此，导出前应尽量使用固定尺寸、明确的页面容器和稳定的字体，避免依赖复杂的响应式布局、悬浮元素或浏览器专属 CSS。

尤其需要检查：

- 页面比例是否为 16:9 或目标演示比例
- 中文字体在目标机器上是否存在
- 图片是否使用可访问的本地路径或稳定 URL
- 长文本是否溢出幻灯片
- 表格和代码块是否跨页或被裁切
- CSS 阴影、渐变和动画是否能在 PPT 中保留

## 与截图导出的区别

截图导出只能得到不可编辑的位图；HTML 转 PPT 的价值在于尽可能保留文字、形状和结构，使后续用户仍可以在 PowerPoint 中修改内容。具体元素是否可编辑取决于工具版本、HTML 结构和使用的 CSS 能力，因此不能把所有浏览器效果都视为可编辑对象。

## 使用建议

- 先建立一套固定的 HTML 幻灯片模板。
- 为标题、正文、表格和图片设置明确的尺寸约束。
- 使用本地字体和本地资源做离线测试。
- 对每一页做渲染截图和 PPT 打开检查。
- 对自动生成的演示文稿保留人工校对环节。
