## 安装一个编程工具

### VS Code

1. 安装 Copilot 插件和 Cline 和/或 Claude 插件，配置其使用 Deepseek API
2. 使用 Copilot 免费额度要求 AI 提示安装插件，用于 java, python / Jupyter 和 NodeJS/TypeScript 开发，以及 VUE 开发
3. 在VS Code 安装 office viewer, drawio
4. 使用 Ai (例如 Copilot 或者 Cline / Claude ) 配置 VS Code 的 java，python 开发环境

### 其他 AI 辅助开发工具
