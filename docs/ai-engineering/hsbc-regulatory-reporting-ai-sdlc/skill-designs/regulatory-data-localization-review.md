# Skill Design: regulatory-data-localization-review

## Purpose

评估需求或实施计划中的数据位置、处理位置、跨境载荷和 Token Vault 边界。

## Trigger

当变更涉及源系统、字段映射、ETL、报送接口、日志、备份、模型调用或部署区域时触发。

## Inputs

- `spec.md` 或 `plan.md`
- 数据字典和分类元数据
- 市场及监管机构
- 数据流、部署和接口元数据

## Checks

1. 原始客户和交易数据是否留在批准的属地。
2. 跨境内容是否仅为已批准的汇总或脱敏结果。
3. 本地副本是否完整、可调取且可验证。
4. Token Vault 是否保持在规定边界内。
5. 日志、备份、缓存、错误信息和模型上下文是否也符合驻留要求。
6. 是否存在数据保护负责人和审批记录。

## Outputs

- 数据流检查表
- 阻断项和待确认项
- 需要人工批准的跨境字段清单
- 证据链接与版本

## Human gate

数据保护和信息安全负责人批准驻留、跨境和模型部署决定。未批准时不得进入生产设计。

## Prohibited behavior

Skill 不读取或复制原始数据，不把原始样本写入报告，不以模型推测替代法规或内部政策。
